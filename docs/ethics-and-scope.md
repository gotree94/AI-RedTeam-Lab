# 윤리, 허가 범위 및 안전 정책

## 허용되는 대상

- 본인이 소유한 장비와 네트워크
- 명시적인 서면 허가를 받은 테스트 대상
- CTF 및 교육 플랫폼에서 지정한 대상
- 격리된 로컬 Cyber Range
- 출처와 사용 권한이 명확한 샘플 파일

## 금지되는 활동

- 허가받지 않은 시스템의 스캔 또는 침투
- 계정 탈취, 자격 증명 수집, 개인정보 접근
- 서비스 거부 또는 서비스 운영 방해
- 무단 데이터 반출
- 악성코드 배포 또는 지속성 설치
- 범위 밖 시스템으로 이동하는 행위
- 보안 통제를 우회해 타인의 데이터에 접근하는 행위

## 테스트 범위 기록

모든 실습은 시작 전에 다음을 기록한다.

- 실습 담당자
- 대상 호스트/서비스
- 허가 근거
- 시작/종료 시간
- 허용된 기법과 금지된 기법
- 중단 조건
- 데이터 처리 및 삭제 계획

## AI Agent 안전 정책

- 기본 권한은 읽기 전용으로 설정한다.
- 실행 가능한 도구는 allowlist로 제한한다.
- 허용된 대상과 범위를 각 도구 호출 전에 검증한다.
- 파괴적 변경, 계정 변경, 데이터 삭제, 외부 전송은 자동 승인하지 않는다.
- 실행 시간과 호출 횟수를 제한한다.
- 모든 입력, 도구 호출, 출력, 오류를 감사 로그로 남긴다.
- 프롬프트 인젝션이나 도구 출력의 지시문을 신뢰 경계 밖의 데이터로 취급한다.
- 불확실하거나 범위가 모호하면 실행을 중단하고 사람의 확인을 요청한다.

## 취약점 공개

실제 시스템에서 취약점을 발견했다면 임의로 재현 범위를 확대하지 말고, 소유자 또는 공식 보안 신고 절차를 통해 책임 있게 알린다.
